# Neon Grid

Example Zhago overlay pack.

This add-on has no backend code. It only provides overlay skins for existing modules:

```text
neon-grid/
  module.json
  overlay/
    match/
      index.html
      index.css
      index.js
    casters/
      index.html
      index.css
      index.js
```

Install it by placing the folder in `ZHAGO_DIR/modules/neon-grid`, then select `Neon Grid` from the Match or Casters cockpit overlay picker.
